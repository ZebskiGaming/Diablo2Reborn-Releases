# DIABLO II: REBORN - Mission statement
=======================================

Diablo II: Reborn exists to bring new life to the game we love without losing what made it great.

We believe Diablo II’s problem was never too much power. It was too few choices. So instead of nerfing the builds, items and strategies players love, we raise up everything that was left behind: forgotten skills, ignored uniques, overlooked mercenaries. Every class should have more than one way to win, and every drop should have a chance to matter.

We respect your time. Grinding is part of Diablo II, but it should be a hunt, not a chore. And through every change, we ask one question: does this still feel like Diablo II?

Reborn is, and always will be, free. No pay-to-win, no shortcuts for sale. Just the game, made better, for the community that kept it alive.

"Requires your own legitimate copy of Diablo II and Lord Of Destruction, patched to 1.14d"

DIABLO II: REBORN - INSTALL GUIDE
=================================

What you need
-------------
- Diablo II and Lord of Destruction, installed from your own Blizzard account.
- Patched to version 1.14d. (Launch the game once and click Battle.net;
  it updates itself. The version shows in the bottom-left of the main menu.)

This patch contains only Reborn's own files. It does not include any
Blizzard game files.

First-time install
------------------
1. Recommended: copy your whole Diablo II folder to a new folder such as
   C:\Diablo2Reborn and install Reborn there. Your normal game stays untouched.
2. Back up your characters: copy the folder
   C:\Users\<you>\Saved Games\Diablo II somewhere safe.
3. Extract this zip into your Reborn game folder, so that:
     - "Play Reborn.bat" sits next to Game.exe
     - a "data" folder sits next to Game.exe
4. Double-click "Reborn-Gateway.reg" and click Yes.
   This sets your Battle.net gateway list to include Reborn.
5. Start the game with "Play Reborn.bat".
6. On the main menu, click the Gateway button and choose "Reborn".
7. Click Other Multiplayer > Open Battle.net, create an account and log in.
   (Do NOT use the main Battle.net button; that is for closed realms.)

Updating to a new patch
-----------------------
1. Delete the old "data" folder from your Reborn game folder.
2. Extract the new zip the same way as above.
3. Everyone in a game must have the same patch. Compare VERSION.txt
   with the host if you get disconnected when joining.

Hosting your own games
----------------------
Joining games works out of the box. To HOST a game that others can join,
forward TCP port 4000 on your router to your PC.

Notes

- Characters on Open Battle.net are saved on your own PC.
- Reborn is a free fan project. Never pay anyone for Reborn items.
